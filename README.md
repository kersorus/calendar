# Часы и цели

Минимальный Android-трекер часов для регулярных норм, дедлайнов и простого учёта времени.

Главная идея приложения: показывать не только сколько часов уже записано, но и сколько нужно делать дальше, чтобы успеть к цели.

## Возможности

- несколько профилей;
- типы профилей:
  - регулярная норма;
  - цель до даты;
  - простой учёт времени без нормы;
- рабочий график для регулярных профилей;
- быстрый график: понедельник–пятница по 8 часов;
- расчёт нормы по рабочим дням;
- таймер с foreground-уведомлением;
- ручное добавление записей через календарь;
- редактирование и удаление записей;
- комментарии к записям;
- календарь в режиме месяца и недели;
- свайп календаря влево/вправо;
- переход к конкретной дате;
- отметка дедлайна на календаре;
- полный лог записей в меню;
- редактирование профиля;
- SQLite-хранилище на устройстве;
- расчёты вынесены в C через Android NDK/JNI.

## Версия 0.6.2

В этой версии улучшен интерфейс календаря и главного экрана:

- дни календаря отображаются как отдельные ячейки;
- нажатие работает по всей ячейке дня;
- свайп работает по пустой области календаря;
- добавлена кнопка перехода к дате;
- профиль можно редактировать;
- лог перенесён в меню `☰`;
- таймер стал компактнее за счёт кнопок-значков.

## Сборка

```bash
./gradlew assembleDebug
```

APK появится здесь:

```bash
app/build/outputs/apk/debug/app-debug.apk
```

## Установка через ADB

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Приватность

Приложение хранит данные локально на устройстве. Аккаунт, облако и синхронизация пока не используются.
