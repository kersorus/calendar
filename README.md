# Часы и цели

Минимальный Android-трекер времени с профилями, календарём, дедлайнами и расчётом нормы.

Главная идея приложения: показывать не только сколько времени уже учтено, но и сколько ещё нужно делать, чтобы успеть закрыть норму или цель.

## Возможности

- несколько профилей;
- типы профилей:
  - регулярная норма за неделю или месяц;
  - цель до даты;
  - простой учёт времени без нормы;
- рабочий график для регулярной нормы;
- быстрый график: понедельник–пятница по 8 часов;
- расчёт нормы по рабочим дням, а не только по календарным;
- таймер с уведомлением;
- пауза, продолжение и остановка таймера;
- ручное добавление записей через дату в календаре;
- редактирование и удаление записей;
- комментарии к записям;
- календарь в режиме месяца и недели;
- листание календаря кнопками и свайпом;
- отметка дедлайна в календаре;
- лог последних записей;
- локальное хранение данных в SQLite;
- расчёты вынесены в C через Android NDK/JNI.

## Рабочий график

Для регулярных профилей можно включить вариант:

```text
Понедельник–пятница по 8 часов
```

В этом режиме месячная норма считается автоматически:

```text
количество рабочих дней в месяце × 8 часов
```

Например, если в месяце 22 рабочих дня, норма будет 176 часов. Если 21 рабочий день — 168 часов.

Отчёт также считает прогресс по рабочим дням, а не по календарным.

## Сборка

```bash
./gradlew assembleDebug
```

APK появится здесь:

```bash
app/build/outputs/apk/debug/app-debug.apk
```
