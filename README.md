# Часы и цели

Минимальный Android-трекер часов с C/NDK-ядром для расчётов.

Идея приложения: не просто считать прошлое время, а отвечать на главный вопрос: **сколько ещё нужно делать в день или неделю, чтобы успеть закрыть норму или цель**.

## Что умеет версия 0.5

- несколько профилей;
- первый запуск с созданием профиля;
- типы профилей:
  - регулярная норма за неделю;
  - регулярная норма за месяц;
  - цель до даты;
  - простой учёт времени без нормы;
- таймер с foreground-уведомлением;
- пауза, продолжение и остановка таймера;
- календарь месяца с отображением трудозатрат по дням;
- добавление записи по нажатию на дату в календаре;
- просмотр записей выбранного дня по нажатию на дату;
- редактирование записи из календаря и из полного лога;
- защита от ручного добавления больше 24 часов в одну дату;
- главный ответ: сколько нужно в день, чтобы успеть;
- подробный отчёт с балансом, остатком и расчётом в неделю;
- ручное добавление записи;
- удаление записи;
- комментарий к записи;
- лог последних записей и полный лог по нажатию;
- локальная SQLite-база без аккаунта и облака.

## Важная логика расчётов

Сегодня считается пройденным днём периода только тогда, когда за сегодня уже есть хотя бы одна запись по выбранному профилю.

Если записей за сегодня нет, сегодняшний день считается доступным для добора часов.

Это нужно, чтобы утром 13-го числа приложение не считало, что 13-й день уже полностью прошёл.

## Ограничения ручных записей

Вручную нельзя записать больше 24 часов на одну календарную дату по одному профилю. Ограничение учитывает сумму всех записей за выбранный день.

## Сборка

```bash
./gradlew assembleDebug
```

APK:

```bash
app/build/outputs/apk/debug/app-debug.apk
```

## Установка

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
