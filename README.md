# Calendar

В репозитории собираются два Android-приложения из одного Gradle-модуля:

- `timecalendar` — «Часы и цели»;
- `warehouse` — «Зарплата».

## Зарплата 0.7.0

Календарь смен и расчёта складской зарплаты.

### Возможности

- графики 2/2, 3/3 и 5/2 по дате любого рабочего дня;
- ручное добавление и удаление смен;
- ввод пиков по отдельным категориям;
- отдельные строки для выдачи, отказов и оплат;
- расчёт стоимости пиков по весовым коэффициентам;
- оплата выхода: 10,75 часа × 147 ₽, если за день есть пики;
- вычет налога 13%;
- сумма смены прямо в календаре;
- зелёная смена при чистом доходе от 5000 ₽;
- контрастная окраска расчётных периодов;
- выплаты:
  - 1–15 число → 25 число того же месяца;
  - 16–последнее число → 10 число следующего месяца;
- две карточки: ближайшая и следующая выплата;
- переход к выбранному месяцу;
- резервная копия через системный файловый провайдер;
- сохранение копии в Google Drive возможно через системное меню Android;
- необязательная фоновая фотография;
- настраиваемые ставка, длительность смены, налог и базовая цена пика;
- иконка `La$`.

## Сборка

Оба APK:

```bash
./gradlew assembleTimecalendarDebug assembleWarehouseDebug
```

Только приложение «Зарплата»:

```bash
./gradlew assembleWarehouseDebug
```

APK:

```text
app/build/outputs/apk/warehouse/debug/app-warehouse-debug.apk
```

## Приватность

Все данные хранятся локально. Облачная копия создаётся только по команде пользователя через выбранный системный файловый провайдер.
