# Calendar

В репозитории теперь два Android-таргета.

## 1. Часы и цели

Минимальный трекер часов для норм, целей и дедлайнов.

Сборка:

```bash
./gradlew assembleTimecalendarDebug
```

APK:

```text
app/build/outputs/apk/timecalendar/debug/
```

## 2. Склад Зарплата

Отдельный таргет для календаря смен и расчёта зарплаты по складским операциям.

Сборка:

```bash
./gradlew assembleWarehouseDebug
```

APK:

```text
app/build/outputs/apk/warehouse/debug/
```

## Склад Зарплата: что умеет

- один главный экран без вертикальной прокрутки;
- календарь месяца;
- меню `График`;
- выбор графика 2/2, 3/3, 5/2;
- ввод даты любого рабочего дня для расчёта смен;
- ручное добавление смены;
- ручное удаление смены;
- ввод количества пиков по типам операций;
- расчёт суммы за пики;
- добавление оплаты выхода в смену при наличии пиков;
- вычитание 13% налога;
- отображение чистой суммы на дате;
- подсветка смен от 5000 ₽ зелёным;
- отображение ближайшей, прошлой и следующей выплаты;
- полный список выплат через меню.

## Формула расчёта

Базовая стоимость пика: `6.1 ₽`.

Весовые коэффициенты:

| Операция | Вес |
|---|---:|
| Отмены | 0.6 |
| Приемка | 0.8 |
| Возвраты | 0.9 |
| Выдача / отказы / оплата | 1.1 |
| Переупаковка | 1.3 |

Дополнительно, если за день есть хотя бы один пик:

```text
10.75 часов × 147 ₽
```

После этого вычитается налог 13%.

## GitHub Actions

Workflow собирает оба APK:

```bash
./gradlew assembleTimecalendarDebug
./gradlew assembleWarehouseDebug
```

Если нужен только складской таргет, команда такая:

```bash
./gradlew assembleWarehouseDebug
```
