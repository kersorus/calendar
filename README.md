# Часы и цели

Минимальное Android-приложение с C/NDK-ядром для учёта часов и прогноза нормы.

Главная идея: приложение не просто показывает, сколько времени уже учтено, а отвечает на вопрос: **сколько ещё нужно делать в день, чтобы успеть закрыть норму**.

## Функции

- несколько профилей: `Работа`, `Учёба`, `Спорт`, `Практика`;
- цель по часам на неделю;
- цель по часам на месяц;
- цель по часам до конкретной даты;
- старт / пауза / продолжить / стоп;
- foreground-уведомление с кнопками;
- сохранение сессий в SQLite;
- отчёт по выбранному профилю;
- прогноз: `нужно в день`, `осталось часов`, `баланс сейчас`;
- все данные хранятся только на устройстве;
- расчёты вынесены в C через JNI.

## Сборка

```bash
./gradlew assembleDebug
```

APK:

```bash
app/build/outputs/apk/debug/app-debug.apk
```

Установка:

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Что изменилось в версии 0.2

Добавлена продуктовая идея, которая отличает приложение от обычного таймера: **прогноз нормы**.

Пример:

```text
Норма: 30 ч за месяц
Факт: 14.2 ч
Осталось: 15.8 ч
Нужно в день: 0.88 ч
```

Это сохраняет минимализм: приложение не превращается в комбайн для инвойсов, команд, клиентов и зарплаты, а остаётся личным локальным трекером часов.
