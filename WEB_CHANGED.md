# Salary PWA storage 0.2

- Основное веб-хранилище перенесено из localStorage в IndexedDB.
- Старые данные localStorage автоматически импортируются при первом запуске.
- После каждого изменения IndexedDB обновляется автоматически.
- Ручные экспорт и импорт JSON сохранены.
- Добавлен File System Access API:
  - пользователь один раз выбирает JSON-файл;
  - после каждого изменения приложение автоматически обновляет его;
  - функция доступна только в поддерживающих браузерах;
  - ручной экспорт работает во всех браузерах.
- Workflow GitHub Pages использует `enablement: true`.
- Google Drive оставлен в roadmap.
