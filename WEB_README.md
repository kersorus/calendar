# Salary PWA 0.1

Веб-версия приложения «Зарплата» для GitHub Pages, iPhone, Android и ПК.

- устанавливается на домашний экран;
- работает офлайн после первого открытия;
- хранит данные локально в браузере;
- экспортирует полную резервную копию в JSON;
- импортирует резервную копию из JSON;
- поддерживает графики, смены, пики и выплаты.

После push включите: `Settings → Pages → Source: GitHub Actions`.

Адрес: `https://kersorus.github.io/calendar/`

На iPhone: `Safari → Поделиться → На экран «Домой»`.
