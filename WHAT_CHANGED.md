# Изменения

## Warehouse target

Добавлен отдельный Android-таргет `warehouse` в этом же репозитории.

### Сборка

```bash
./gradlew assembleWarehouseDebug
```

### Добавлено

- отдельный launcher `Склад Зарплата`;
- отдельный `applicationId`: `com.kersorus.warehousepay`;
- календарь смен на одном экране;
- графики 2/2, 3/3, 5/2;
- ввод даты любого рабочего дня для расчёта графика;
- добавление и удаление смен вручную;
- ввод пиков по типам операций;
- расчёт оплаты за пики;
- добавление оплаты выхода в смену при наличии пиков;
- вычитание 13% налога;
- подсветка дней от 5000 ₽ зелёным;
- расчёт выплат 10 и 25 числа;
- GitHub Actions собирает оба таргета.
