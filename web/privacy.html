Политика конфиденциальности La$

Последнее обновление: 22 июля 2026 года.

Назначение приложения

La$ предназначено для личного учёта смен, настройки рабочего графика и ориентировочного расчёта зарплаты. Подключение Google необязательно: без него приложение продолжает работать локально.

Какие данные обрабатываются

Приложение обрабатывает введённые пользователем смены, параметры графика и настройки расчёта. После подключения Google также используются идентификатор аккаунта, имя и адрес электронной почты, чтобы определить владельца резервной копии и показать подключённый аккаунт. Браузер передаёт серверу одноразовый код авторизации Google; постоянные Google-токены в браузер не возвращаются.

Приложение не получает пароль Google и не читает обычные документы пользователя в Google Drive. Запрашивается доступ только к закрытому пространству данных приложения.

Где хранятся данные

Рабочая копия хранится в браузерной базе данных на устройстве. Облачная копия размещается в appDataFolder Google Drive. Cloudflare Worker хранит сведения о сессиях и refresh token Google, зашифрованный AES-256-GCM, в изолированных SQLite-backed Durable Objects. В браузере хранится только случайный идентификатор сессии.

Как используются и передаются данные

Данные используются только для сохранения, восстановления и объединения информации между устройствами. Они не продаются, не применяются для рекламы, кредитного скоринга или профилирования и не передаются независимым третьим лицам.

Для работы функции синхронизации данные обрабатываются сервисами Cloudflare Workers, Google OAuth и Google Drive. Автоматическая обработка ограничена техническими операциями, необходимыми для предоставления пользователю этой функции.

Использование информации, полученной через Google Workspace APIs, соответствует Google API Services User Data Policy, включая требования Limited Use.

Срок хранения и удаление

Сессия Cloudflare Worker продлевается при использовании приложения и удаляется после периода бездействия либо при отключении устройства. Команда «Отозвать доступ» удаляет сохранённый refresh token и завершает сессии на всех устройствах, но оставляет резервную копию в Google Drive для возможного повторного подключения. Доступ также можно отозвать в настройках безопасности Google-аккаунта.

Команда «Удалить облачную копию» удаляет данные приложения из закрытого пространства Google Drive, сохранённый refresh token и все серверные сессии. Локальная копия на текущем устройстве при этом сохраняется. Локальные данные удаляются отдельно средствами браузера или приложения.

Безопасность

Передача выполняется по HTTPS. OAuth Client Secret и ключ шифрования хранятся только на серверной стороне. Сервер не выводит Google-токены в ответы API или журналы приложения.
